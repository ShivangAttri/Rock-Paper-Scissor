# Rock Paper Scissors – Score Keeper 🎮

A simple Rock Paper Scissors score keeper web app built using **HTML, CSS, JavaScript** and **Bulma CSS**.

## ✨ Features
- Interactive Rock, Paper, Scissors buttons
- Hover animations and custom styling
- Score tracking for Player 1 and Player 2
- “Playing To” selector
- Reset functionality
- Clean UI using Bulma

## 🛠️ Tech Used
- HTML5
- CSS3
- JavaScript
- Bulma CSS Framework
